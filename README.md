# Expired GMB Domain Pipeline

Daily snapshot of expired, dropping and auction .com/.net/.org domains with Google Business Profile history or
plumbing / HVAC / water names, scored by the Expired GMB Domain Finder (`xd`).

Open the site: https://loftenter.github.io/expired-gmb-dashboard/

The page and `data/*.json` are regenerated every morning from a local database. Do not edit them here.
